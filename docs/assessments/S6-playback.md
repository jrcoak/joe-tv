# S6 Playback — caption defaults and quiet-volume automation

September 20, 2026. Original Joe-TV baseline `46256bc`, branch `codex/joe-tv-playback-s6`. Scope is `PlaybackSession`, full-screen caption controls, a pure policy test and this report. Player, FairPlay, live-edge, preferred audio, preview ownership and provider code remain intact.

Every real `PlaybackSession` explicitly selects Off when its legible group permits an empty selection. It observes `AVAssetMediaSelectionGroupsDidChange`, reapplies the group-specific selection when a late or changed group appears, retries transient initial load failures twice, and retains a usable group through later refresh errors. AVPlayer automatic media selection stays enabled so preferred audio is never blocked by a pending legible load. Apple documents that `AVPlayerItem.select(nil, in:)` overrides automatic selection for that group until automatic selection is explicitly requested again ([selection API](https://developer.apple.com/documentation/avfoundation/avplayeritem/select%28_%3Ain%3A%29), [criteria API](https://developer.apple.com/documentation/avfoundation/avplayer/appliesmediaselectioncriteriaautomatically)). Content whose legible group forbids empty selection cannot truthfully offer Off; the UI omits that action. If AVFoundation never exposes a loadable legible group, the app cannot install a group-specific Off override; the notification and bounded retries cover late and transient availability without delaying audio indefinitely.

The full-screen caption dialog remains available even before tracks are found. It offers manual tracks plus persistent automatic choices: Off, Muted/0%, 5%, 10%, and 20%. The PM-recommended default is 10%. Captions remain Off above the selected entry threshold; a two-point hysteresis band prevents toggling near the boundary. Automatic captions rank the player’s preferred legible languages first, then CC/SDH accessibility characteristics, with source order as the deterministic fallback. When volume rises or the signal becomes unknown, an automatically selected track returns to Off. A manually selected track is never replaced, including across a group refresh when the same stable option identity returns. Manual Off suppresses re-enabling until that quiet episode ends.

Only `PlayerSessionView` starts the volume observer, so guide/Home previews never receive automatic caption decisions. Disappearance invalidates an observation generation before publishing unknown volume, so an already queued KVO delivery cannot restore a stale quiet sample after monitoring stops. No app mute control was added because the existing player has no mute control that would provide stronger evidence.

Apple documents `AVAudioSession.outputVolume` as a KVO-observable system volume from 0 to 1 ([API](https://developer.apple.com/documentation/avfaudio/avaudiosession/outputvolume)). The tvOS 26.5 SDK marks `AVAudioSession.isOutputMuted` unavailable on tvOS, and no public AVPlayer automatic-subtitles-on-mute property was found. Apple TV’s own Show When Muted feature warns that infrared-controlled TV volume is unsupported ([Apple TV guide](https://support.apple.com/guide/tv/atvb7d97de8b/tvos)). Joe-TV therefore treats only finite in-range `outputVolume` samples as evidence, labels the control as a device-volume threshold, and tells viewers that TV/receiver volume may be invisible. It does not infer HDMI, receiver or infrared state.

`sh scripts/test-caption-policy.sh` passes 30 focused checks. It covers unknown/invalid signals, all boundary classes, hysteresis, quiet lifecycle, manual track retention, manual-Off episode suppression, mode changes, preferred-language ranking, accessibility tie-breaking and deterministic fallback. The existing FairPlay deprecation warning is unchanged. An isolated unsigned Debug tvOS simulator build succeeded after the caption dialog and input modifiers were split into compiler-sized view expressions. No simulator launch, provider, media, device, installation or project edit ran. PM/QA still need the existing caption fixture to verify startup behavior, late group changes, rendered track changes, focus/Back, persistent choice and lifecycle; physical Apple TV must check actual route reporting and external TV/receiver mute limits.
