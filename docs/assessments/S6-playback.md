# S6 Playback — caption defaults and quiet-volume automation

September 20, 2026. Original Joe-TV baseline `46256bc`, branch `codex/joe-tv-playback-s6`. Scope is `PlaybackSession`, full-screen caption controls, a pure policy test and this report. Player, FairPlay, live-edge, preferred audio, preview ownership and provider code remain intact.

Every real `PlaybackSession` attaches a suppressing `AVPlayerItemLegibleOutput` before inserting the item into AVPlayer. AVFoundation can prepare preferred audio normally, while legible cues cannot render until a usable group receives an explicit selection. The session selects Off when the group permits an empty selection, applies the current manual or quiet-volume choice when needed, then removes the rendering gate. It observes `AVAssetMediaSelectionGroupsDidChange`, reapplies policy when a late or changed group appears, retries transient initial load failures twice, and retains a usable group through later refresh errors. Apple documents that `AVPlayerItem.select(nil, in:)` overrides automatic selection for that group until automatic selection is explicitly requested again ([selection API](https://developer.apple.com/documentation/avfoundation/avplayeritem/select%28_%3Ain%3A%29), [output API](https://developer.apple.com/documentation/avfoundation/avplayeritemoutput/suppressesplayerrendering)). Content whose legible group forbids empty selection cannot truthfully offer Off; the UI omits that action. If AVFoundation never exposes a loadable legible group, the gate remains attached and suppresses legible rendering without delaying audio.

The full-screen caption dialog remains available even before tracks are found. It offers manual tracks plus persistent automatic choices: Off, Muted/0%, 5%, 10%, and 20%. The PM-recommended default is 10%. Muted/0% exits as soon as reported volume rises above zero; the percentage thresholds use a two-point hysteresis band to prevent toggling near their boundaries. Automatic captions rank the player’s preferred legible languages first, then CC/SDH accessibility characteristics, with source order as the deterministic fallback. When volume rises or the signal becomes unknown, an automatically selected track returns to Off. A manually selected track is never replaced. Its semantic identity uses language, display name and accessibility kind rather than source index, so ordinary option reordering does not lose the choice. Manual Off suppresses re-enabling until that quiet episode ends.

Only `PlayerSessionView` starts the volume observer, so guide/Home previews never receive automatic caption decisions. Disappearance invalidates an observation generation before publishing unknown volume, so an already queued KVO delivery cannot restore a stale quiet sample after monitoring stops. No app mute control was added because the existing player has no mute control that would provide stronger evidence.

Apple documents `AVAudioSession.outputVolume` as a KVO-observable system volume from 0 to 1 ([API](https://developer.apple.com/documentation/avfaudio/avaudiosession/outputvolume)). The tvOS 26.5 SDK marks `AVAudioSession.isOutputMuted` unavailable on tvOS, and no public AVPlayer automatic-subtitles-on-mute property was found. Apple TV’s own Show When Muted feature warns that infrared-controlled TV volume is unsupported ([Apple TV guide](https://support.apple.com/guide/tv/atvb7d97de8b/tvos)). Joe-TV therefore treats only finite in-range `outputVolume` samples as evidence, labels the control as a device-volume threshold, and tells viewers that TV/receiver volume may be invisible. It does not infer HDMI, receiver or infrared state.

`sh scripts/test-caption-policy.sh` passes 34 focused checks. It covers unknown/invalid signals, all boundary classes, hysteresis, muted-only exit behavior, quiet lifecycle, manual track retention, manual-Off episode suppression, mode changes, preferred-language ranking, accessibility tie-breaking, deterministic fallback and stable semantic track identity. The existing FairPlay deprecation warning is unchanged. An isolated unsigned Debug tvOS simulator build succeeded before this final gate-only correction; PM owns the final combined build. No simulator launch, provider, media, device, installation or project edit ran. PM/QA still need the existing caption fixture to verify startup suppression, late group changes, rendered track changes, focus/Back, persistent choice and lifecycle; physical Apple TV must check actual route reporting and external TV/receiver mute limits.
