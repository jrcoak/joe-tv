## Async transitions and limits

`AppModel` is main-actor isolated. Each entered non-fixture refresh rotates `epgRequestID` before loading/no-channel handling. The equality guard at 985 precedes both result assignments without an intervening await. A later entered refresh therefore prevents an older completion from publishing its captured snapshot. `signOut` clears state/mappings and synchronously rotates the ID (1757–1799), so a refresh already in flight before sign-out cannot publish through this guard. Provider order remains Very Local then XMLTV; no new timeout/retry/cancellation mechanism is introduced. The guard does not prove correctness of unrelated catalog tasks or refresh tasks that have not yet entered when sign-out occurs.

Non-blocking pre-existing follow-up: `openVeryLocal` (1801–1818) clears state/mappings but does not synchronously rotate the request ID; that happens only when its queued refresh enters. If this method is invoked while a previous guide completion is queued, that completion could publish between the reset and the next refresh, which could then capture the old snapshot. The same method body exists in a8301bc, and a repository source search found no current call sites beyond its declaration. This is a dormant transition hardening opportunity, not a newly introduced or runtime-reproduced S3 defect. Before reactivating that entry point, invalidate guide work synchronously and exercise the transition with controlled async completions. No source change is requested as part of this report-only review.

## UI compatibility and QA handoff

`JoeTVExperience`'s `EPGLoadState.usableWindow` (3406–3414) and AppModel's `usableGuideWindow` (1849–1855) already expose cached windows during loading/failure. Home current/next program lookup, guide station lookup, and Quick Switch titles therefore consume retained listings without a new model interface. `JoeTVGuideView.epgStatus` shows the existing partial-availability status; the grid retains channel buttons even when a station has no programs. No UI consumer uses `fetchedAt` as a gate or freshness claim.

Guide rows remain keyed by channel identity and program buttons by program identity. Retention preserves those IDs for failed-source rows. `restoreOrigin` (JoeTVExperience 608–633) resolves a surviving visible program or falls back to its channel, preserving the S1 return contract after authoritative replacement/removal. The grid filters to its own displayed window and clips only drawing geometry, consistent with retaining original long-program times. This source audit does not establish focused-cell behavior during an in-place async replacement, actual scroll restoration, or visual legibility.
